# 动态分类与七区直达交付说明

日期：2026-09-19。本轮范围来自用户连续确认的展示板筛选、后台自定义分类、七区直达、360°旋转、步行缩放与大厅提速。

## 展示板与后台配置

前台使用“搜索称号 / 称号分类 / 开放版块”三个统一样式控件。搜索支持名称和简介；下拉采用蓝白浮层、选中标记、键盘方向键/Enter选择、Esc收起菜单。手机搜索独占一行，另外两项并列。

在运营管理中心 → 版块管理 → AI服务中心 → 展示板与资料中：

1. 新增分类、修改名称、调整顺序、设置是否公开。分类可以是学习类、共创类等，名称不写死在前台。
2. 勾选“展示板开放版块”。当前未设置时默认只有AI服务中心；可以配置为空。
3. 保存草稿不会改变前台，点击“发布展示配置”后生效。
4. 在“身份称号”编辑页选择已发布分类，再发布称号。

荣誉／权限继续作为原有业务属性，与分类独立。大厅两块3D展示板分别按业务属性进入列表，“清除筛选”可以查看全部。分类不授予业务权限或后台角色。

前台菜单读取 `/api/service` 返回的 `filters`，不再固定列举两种类型和七个版块。关闭分类或版块后，其菜单和相关称号卡片从展示板撤下；原有身份、申请及已公开详情的直接访问规则不变。该开关是展示板目录设置，不是其他模块的上线开关。

已有未分类称号在“全部分类”中保持可见。没有配置任何分类时只显示“全部分类”，不虚构正式分类或称号。接口不输出未公开分类名称；已有称号引用的分类不能通过接口删除，可关闭公开展示。

配置存储于现有 `town_service_content` 的草稿/发布JSON内，称号新增可选 `category` 字段；旧数据兼容，无数据库迁移。沿用服务内容岗位权限、版本冲突校验和操作审计。

## 场景与导航

- 服务大厅与小镇全景沙盘均可连续360°水平旋转。大厅从后面观察时自动隐藏遮挡的后墙，俯仰仍有限制。
- 小镇第三人称步行支持滚轮缩放，默认距离7，范围5.2–60（最新调整：最远距离由20扩大到60，默认距离7不变；拉远时平滑抬高镜头，扩大周边版块视野）；第一视角以48–72°视野范围缩放。保留建筑遮挡检测，防止镜头穿入建筑。
- 小镇用户角色普通/Shift移动速度由5.5/9提高为8.25/13.5，键盘和摇杆共用速度，保留碰撞、互动暂停和原有NPC速度。
- 服务大厅普通行走速度由3.6提高到5.2，Shift加速由6提高到8，保留碰撞与弹窗暂停。
- 七个门口保留黄色地面圆环；仅全景沙盘在圆环上方显示长凳同款金橙色倒角边缘（#f69826）的小尺寸立体黄色向下箭头，步行模式不显示箭头。箭头缓慢上下浮动，减少动态偏好下静止。按一次E直接进入子页面，不再先弹服务向导确认。
- 全景沙盘箭头与步行入口黄圈共用坐标，箭头放在门口；全景点击箭头直接进入。箭头约26px（手机22px），保持44px透明点击范围及辅助阅读名称。
- 步行导航补齐AI广场和任务广场；落点与入口标记统一。
- 所有子页面返回链接统一为 `/`，通过当前标签页的一次性场景状态选择落点；使用后立即清除，不在网址中固定角色位置。旧 `?return=` / `?resume=` 链接仅作为一次性兼容入口，加载后自动清理参数。普通首页刷新无待恢复状态时仍打开欢迎页。

## 个人中心返回现场

从小镇进入个人中心时，在当前标签页的sessionStorage保存角色实际坐标、朝向、第一/第三视角、步行缩放、坐姿及全景镜头角度。个人中心品牌和“返回小镇”链接将保存的现场放入一次性恢复状态，然后通过 `/` 返回；刷新个人中心后仍可返回，恢复前仅显示加载提示，不先经过欢迎页。保存内容不包含账户或权限。清空移动、打字与对话状态，防止返回后自动走动。

没有有效记录时安全回到正常欢迎页；直接访问 `/` 不自动恢复。保存为当前标签页的最后一次小镇现场，NPC、车辆与临时聊天内容不保存。`data/town-return.ts` 校验记录版本、坐标/镜头范围及可站立性，`TownEntry.tsx` 在加载并消费一次性恢复记录后再挂载场景；`TownReturnLink.tsx` / `data/town-navigation.ts` 负责个人中心和七区的统一返回。

## 六个介绍子页面

服务中心继续使用已有完整办理功能。其他六区使用 `/districts/[id]`，分别提供介绍、三项规划方向、筹备状态、返回本区门口与服务中心链接。

支持：learning-campus、office-campus、creative-street、ai-community、town-square、task-square。未知版块返回404。页面明确标注“功能筹备中”，没有虚构课程、任务、交易、住房分配或多人功能。

## 主要开发位置

- `lib/service.ts`、`lib/server/service-titles.ts`：动态分类、公开过滤、后台校验。
- `components/service/ServiceBoard.tsx`、`ServiceFilterSelect.tsx`、`ServiceCatalogEditor.tsx`：筛选与分类设置。
- `data/district-entries.ts`：七区入口、路由、返回白名单与交互距离。
- `components/town/DistrictEntries.tsx`、`TownExperience.tsx`、`TownControls.tsx`、`WalkControls.tsx`：箭头、E键直达和镜头。
- `data/district-introductions.ts`、`app/districts/[id]/page.tsx`：六区介绍。
- `data/walk-camera.ts`、`components/service/hall/HallCanvas.tsx`、`HallScene.tsx`：有限步行缩放、大厅提速与360°剖面。
