# 第七批：随机漫步与环境声（V0.7）

用户已确认四项修改，并补充将声音换成更安静的环境声。本批保留已有七区布局、NPC 对话、玩家气泡与交通功能。

## 本次修改

- 32 位 NPC 从固定往返改为街区内的随机短途漫步。每段随机方向、目的地、步速和停留时间，平滑转身；使用现有碰撞数据避开建筑、水景、绿化和主要设施，遇到人物受阻后等待或重新选择方向。初始人物分布保证安全间距。对话期间停下，结束后继续。
- 学院楼顶改为较小的“AI教学楼”蓝白立体标牌，学院门头仍为“五六零AI学院”；补充本地“教”字轮廓。
- 环境声每次加载页面默认关闭，进入小镇不触发播放。只有手动开关可以激活，浏览器只保留音量偏好，忽略旧版已开启状态。
- 音源换成《海风轻浪》：本地生成的柔和宽频海风与远处浪声模拟，无旋律、人声或外部音频采样，72 秒循环。首次默认音量 12%，音源 RMS 约 0.043。保留淡入淡出、对话降音量和隐藏页面暂停机制。
- 移除首页底部七区长条图例，保留精简操作提示与步行模式的前往按钮。调整环境声控件位置和全景取景，完整展示底座。

## 验证

- `npm.cmd run typecheck` 通过；生产构建通过。
- 15 项测试通过，覆盖布局、碰撞、交通、发言、随机 NPC 漫步、对话暂停和默认关闭的音量设置。
- 随机漫步测试用 3 个种子分别模拟 120 秒，确认居民走动和停留、二维移动、街区边界、连续速度、静态障碍和人物间距。
- 浏览器验证桌面与 390 × 844 手机尺寸；确认首页图例移除、学院招牌缩小、步行界面与 NPC 对话可用。
- 浏览器实际确认音源加载为 72 秒循环，初始与进入小镇均暂停、手动开启播放、刷新后重新关闭。浏览器未发现运行错误。
- 手机验证为浏览器尺寸模拟；环境声音色属于合成模拟，最终听感仍可按用户实际设备反馈调整。
