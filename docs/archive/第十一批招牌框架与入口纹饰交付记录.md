# 第十一批：招牌框架、入口纹饰与缺字修复（V0.11）

用户确认招牌框架重设计，并补充服务中心屋顶需区别于创业园。实施期间，用户确认了门头花纹、两侧对联，并要求修复“创作工坊”显示问题。

## 完成内容

- 框架跨度根据现有牌面实际字形宽度计算，不再沿用旧的宽横梁和立柱位置。学院采用紧凑三角门头，创业园采用非对称支架，商业街采用短悬挂架与彩旗，社区采用贴合牌面的圆弧门头，广场采用小型流线支架，服务中心采用贴墙框和短檐，任务广场标题檐与公告栏按层次缩窄。
- 模型和碰撞共享 `data/district-signs.ts` 中的立柱位置、底座尺寸。旧立柱碰撞移除，新立柱阻挡生效，五个街区门头中间仍可通行。
- 服务中心主屋顶改为柔和珊瑚橙（`#eb927e`），与创业园暖沙色区分；保留蓝底白字及蓝白外墙。
- 主入口顶梁增加浅蓝海浪浮雕，门头两端增加细电路纹样。面对入口时，右联为“智汇五六零启新境”，左联为“梦起北部湾创未来”；均为蓝底白色立体字，自上而下竖排。
- “创作工坊”名称本身正确，原问题为本地字形缺少“坊”，现已补齐。新增检查覆盖所有店铺、楼栋、街区招牌和入口对联字符，防止遗漏字形显示为问号。

## 验证

- 类型检查、17 项测试及生产构建通过。
- 测试覆盖新立柱阻挡、中间通道可达、人物随机漫步、原有交通与碰撞，以及所有当前立体招牌字符的字库覆盖。
- 浏览器检查桌面全景、主门近景、手机尺寸及进入小镇；对联文字完整，其他招牌字号保持不变，框架与牌面协调，未报告渲染错误。
- 手机检查采用浏览器尺寸模拟。
