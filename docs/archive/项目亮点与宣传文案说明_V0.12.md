# 五六零人工智能AI小镇｜项目亮点与宣传文案说明

版本：V0.12｜更新日期：2026-09-18  
使用方法：将本文件完整发给宣传 AI，即可用于创作介绍、海报、朋友圈、公众号及短视频脚本。本文件独立完整，不需要项目代码或开发交接记录。

## 一、先用一句话理解项目

**五六零人工智能AI小镇，是一个把 AI 学习、创业、创作与社区生活的主题，呈现在可浏览、可漫游、可互动的 3D 小镇中的数字场景项目。**

由 **五六零人工智能科技（北海）有限公司** 打造。当前已完成七个主题街区的场景和多项基础互动，处于场景与体验持续完善阶段。

宣传首先要让人感受到：这里有一座看得见、走得进、可以慢慢探索的小镇。学习、创业和社区服务是空间设计表达的方向，具体业务将来再逐步接入。

## 二、最值得宣传的六个亮点

### 亮点 1：一座可以亲自走进去的立体小镇

用户可以先从全景观察完整布局，再操控绿色小人走进街区。支持第三人称跟随和第一视角浏览，能旋转视角、放大观察，沿着道路探索建筑与庭院。

**用户感受：** 从远处看小镇，到近处逛小镇，拥有主动探索空间的参与感。

**适合的文案方向：** “从全景看见小镇，再用自己的脚步认识它。”这类句子属于创作文案建议，并非已经确定的品牌口号。

**配合画面：** 全景沙盘 → 蓝白主入口 → 绿色角色向街道内部行走。

### 亮点 2：七个街区，形成清晰的探索路线

小镇把学习、创业、工具与创作、公共交流和生活休息等主题安排在不同区域。每个区域有自己的建筑、配色和招牌，既统一又容易辨认。

**用户感受：** 有明确的方向和目的地，不需要在一张复杂地图里找入口。快捷导航会固定到对应门口、招牌下方。

**配合画面：** 学院庭院、创业园组团、商业街两侧店铺、社区住宅依次出现。

| 七个街区 | 已建场景 | 适合传达的主题 |
| --- | --- | --- |
| 五六零AI广场 | 水景、560 海浪雕塑、开放空间 | 相遇、停留、小镇的中心地标 |
| 五六零AI服务中心 | 蓝白服务大厅与门前区域 | 认识小镇、未来服务入口的空间形象 |
| 五六零AI学院 | 教学楼组团、庭院与学院门头 | 好奇心、学习、实践与成长 |
| 五六零AI创业园 | 多栋办公楼、庭院和园区门头 | 把灵感变成项目的愿景 |
| 五六零AI商业街 | 十间店铺与步行街 | AI 工具、创意作品、探索和灵感 |
| 任务广场 | 三栏任务墙与示意任务卡 | 以挑战连接学习和创作的未来方向 |
| 五六零AI社区 | 四栋住宅、庭院、水景与座椅 | 归属感、邻里生活和休息 |

表中的主题是空间定位。学院不等于已有课程，创业园不等于已有孵化服务，任务墙不等于任务已经可领取。

### 亮点 3：小镇有走动的居民，也有日常的节奏

演示居民会在各自街区散步、停留和转向。靠近时可以按 E 或点击提示聊天，听到与当前位置有关的话语。车辆自动通行，控制密度，并有行人让行效果。

**用户感受：** 街道有动态、有细节，也有可以主动触发的小互动。

**配合画面：** NPC 经过 → 对话图标出现 → 商业街居民说“你也来商业街看看有什么好玩的 AI 呀？” → 一辆车从街角驶过。

**准确边界：** NPC 是演示居民，使用预设台词，不是在线真人或大模型实时问答。

### 亮点 4：可以表达，也可以坐下来休息

用户可以输入文字，让绿色角色头顶出现短暂的气泡；还可以靠近长凳坐下、环顾场景，再起身继续逛。人物头顶的小箭头帮助辨认自己的角色。

**用户感受：** 除了移动和观看，也能留下一句话，给自己的探索安排节奏。

**配合画面：** “今天来小镇找点灵感”的气泡 → 长凳坐姿 → 转动视角看庭院。

**准确边界：** 气泡目前只在本地显示，不能描述成真人聊天或多人社交。

### 亮点 5：明亮的滨海气质与微缩建筑美感

整体为明亮蓝白的立体微缩小镇。暖沙、薄荷绿、珊瑚橙及商业街蓝橙色作为少量辅助色，形成有层次的街区。蓝天白云、绿化、水景和可手动开启的轻柔环境声，共同营造轻松的浏览氛围。

**用户感受：** 科技主题也可以明亮、亲切，有生活气息。

**配合画面：** 白云天空 → 有立体字的蓝白门头 → 彩色遮阳棚 → 水景与绿化。

**准确边界：** 项目具有北海和北部湾意象，是虚拟概念场景，不是真实城市复刻。环境声默认关闭，由用户自行开启。

### 亮点 6：带有五六零品牌记忆的空间

主入口使用完整名称“五六零人工智能AI小镇”，广场设置蓝色 **560 与海浪组合雕塑**，整体缓慢旋转。建筑招牌采用立体白字，各街区框架有自己的造型。页面底部显示公司全称。

两侧对联：**智汇五六零启新境 / 梦起北部湾创未来**。

**用户感受：** 能通过门头、地标和地域意象记住项目，而不只是记住一个页面标题。

**配合画面：** 主门名称与对联特写 → 560 海浪地标旋转 → 公司署名。

主门上方装饰细线和电路纹已移除，不要继续当作最新画面的亮点；广场海浪雕塑保留。

## 三、推荐的宣传主线

建议按照一次真实的参观顺序组织文案：

**看见完整小镇 → 从主门进入 → 探索七个街区 → 与居民聊一句 → 坐下看看风景 → 认识五六零与北部湾的品牌意象 → 关注小镇后续成长。**

这条主线可用于视频、图文、现场演示。短内容挑两三个亮点即可；长内容再介绍七区，不要一开始就堆满建筑名称和技术参数。

推荐读者：对 AI 学习、创作、创业感兴趣的人，以及想了解公司数字场景探索的访客。这是传播对象建议，不是现有用户规模或画像数据。

现有页面短句：

- 学习 · 创业 · 生活，在这里相遇。

- “走进五六零AI小镇，让好奇心带你逛一逛。”
- “从一座小镇出发，看看学习、创作与生活的更多想象。”
- “沿着街道找灵感，也给自己留一张可以坐下的长凳。”
- “在蓝天与海浪之间，认识一座正在成长的 AI 小镇。”

可用于介绍开头的事实底稿：

> 五六零人工智能AI小镇，以明亮的 3D 微缩场景，呈现学习、创业、创作与社区生活的七个主题街区。你可以从全景看见它，也可以操控绿色小人走进街道，与演示居民聊几句，在长凳上休息，看看缓慢旋转的 560 海浪地标。目前，小镇正持续完善场景与基础交互，更多业务内容将根据后续规划逐步接入。

## 五、现阶段的事实边界

宣传可突出：七区场景、游客免登录浏览、全景与角色漫游、第一视角、固定门口导航、预设 NPC 场景对话、本地文字气泡、长凳互动、动态交通、蓝天与品牌雕塑。

以下尚未实现，不能写成已经开放：真实登录、课程学习系统、企业入驻、商品交易、任务接单与奖励、住宅分配装修、好友拜访、多人在线、大模型 NPC、建筑室内、一键换肤。

不要虚构政府背景、合作伙伴、资质、用户数、营收、收益或行业排名。不要把住宅场景写成房产权益，也不要把虚拟创业园写成实体园区或真实孵化成果。

当前没有确认的外网链接、正式发布日期和报名联系方式。初稿使用占位符或省略；`localhost:3000` 只在开发者本机有效，不是公众访问地址。“已正式上线”“正在公测”“立即报名”等表述须有负责人另行确认的信息。
