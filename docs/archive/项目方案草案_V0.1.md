# 五六零 OPC 3D 小镇：项目方案草案 V0.1

状态：待用户确认。本文件是设计提案，不代表功能已经开发或已获开发授权。

后续决策：主入口与访问流程以《主入口与访问流程规划_V0.2.md》为准。用户已确认允许游客浏览、真实登录后置，当前优先完成场景设计与视觉验证。下方原始入口与首屏提案如有冲突，以 V0.2 为准。

依据：《五六零_OPC_3D小镇_Codex开发需求文档_V1.0.md》。

## 1. 协作与范围约定

- 每次开发前，先简要列出本次要做的事情和预期效果，等待用户确认后实施。
- 确认仅覆盖当次清单；新增功能、扩大范围或重要方案变更需要重新确认。
- 确认本设计方案不等于授权全部开发，进入开发前另列具体实施清单。
- 当前仅获授权整理布局草案、六个场所外观说明和首版界面说明。
- 第一阶段验证视觉、布局、场所识别和基本交互，不实现登录、实际权限、室内、交易、多人在线和人物移动等后续业务。

## 2. 总体设计方向

以蓝白科技风、低多边形、滨海微缩沙盘为主。采用简洁几何体构造建筑，以体量、轮廓、标牌和辅助色区分功能。

建议主体白色 #F4F8FC、科技蓝 #2878E8、青色 #35C9D0、深蓝文字 #163454。绿色用于任务与成长、橙色用于商业街、紫蓝色用于办公。色值为设计建议，尚未锁定。

第一版选择“数字光环＋560 标识”作为中心地标，便于通过程序化几何体表达。海豚或湾仔形象保留为后续可替换的地标方向；当前没有正式形象素材，不自行定义其品牌造型。

## 3. 小镇布局草案

以下是逻辑俯视图，北方位于图上方，不代表最终镜头截图。场所尺寸与道路宽度在获准开发后通过画面验证。

```text
                             北
           绿化与预留区                 绿化与预留区
                       ┌──────────────┐
                       │  OPC 教学楼  │
                       └──────┬───────┘
       ┌───────────┐          │
       │ 政务大厅  ├──────┐   │
       └───────────┘      │   │
   ┌─────────────┐    ┌───┴───┴──────┐    ┌─────────────┐
西 │ OPC 写字楼  ├────┤ 小镇中心广场 ├────┤ OPC 商业街  │ 东
   └─────────────┘    │ 地标 / 居民  │    │ 低层店铺组  │
                      └──────┬───────┘    └─────────────┘
                             │
                      ┌──────┴───────┐
                      │ OPC 任务广场 │
                      └──────────────┘
                滨海步道、少量棕榈树与水景
                             南
```

布局要点：

1. 中心广场承担主要视觉焦点，五个功能场所通过短距离道路接入。
2. 政务大厅安排在中心广场西北侧，与西侧写字楼保持间距。
3. 海岸集中在南侧及东南边缘，避免水景切断功能区之间的道路。
4. 外围保留少量连续空地，用绿化表现，不添加不可使用的扩建按钮。
5. 写字楼位于西侧，但控制高度与退距；首屏视角建议从东南看向中心，让任务广场和商业街处于前景。实际遮挡情况以开发后的画面检查为准。
6. 任务广场为开放空间，与中心广场通过公告牌、铺装和绿色标识区分。

## 4. 六个场所外观

| 场所 | 体量与轮廓 | 颜色与标识 | 关键可见元素 |
| --- | --- | --- | --- |
| 小镇中心广场 | 圆形或圆角广场，保持开阔 | 蓝白＋青色；560 地标 | 数字光环、公告屏占位、居民出生点、少量座椅 |
| 政务大厅 | 低层、对称、宽门厅 | 白色＋深蓝；清晰中文名称 | 宽台阶、入口雨棚、抽象服务标识，不使用真实政府徽章 |
| OPC 教学楼 | 中等高度的横向楼体，分段体块 | 白色＋科技蓝；书本形几何标识 | 规律窗格、明显主入口、少量青色装饰 |
| OPC 写字楼 | 全镇最高但克制的竖向楼体 | 白色＋紫蓝；竖向立面线条 | 简化玻璃色块、办公入口平台 |
| OPC 商业街 | 3—4 个低层店铺模块形成短街 | 白色主体＋橙色雨棚 | 各异店面、小招牌，整条街显示一个主要场所名称 |
| OPC 任务广场 | 开放式铺装广场，无封闭主楼 | 白色＋绿色 | 大型任务公告牌、低矮台阶、集合标识 |

所有核心场所都可选中，中心广场和任务广场也拥有明确的可点击区域。商业街第一版按一个场所展示介绍，店铺仅为可扩展的外观模块。

建筑名称建议使用覆盖在场景上的中文标签，保持清晰可读；第一版六个名称均需可见，优先通过间距与标签位置避免重叠。

## 5. 首版界面

### 5.1 桌面端

- 全屏 3D 场景作为主体，页面打开后直接进入小镇。
- 左上角显示“五六零 OPC 3D 小镇”名称及简短阶段标识。
- 左下角显示操作提示：“拖动旋转 · 滚轮缩放 · 点击场所查看介绍”。
- 点击场所后，右侧出现轻量信息卡片，尽量保留小镇可视范围。
- 不设置业务导航侧栏、登录入口或装饰性业务按钮。

### 5.2 手机端

- 保持同一场景和信息结构，根据屏幕比例调整初始取景，让核心区域进入画面。
- 顶部品牌区域缩短，操作提示改为“单指旋转 · 双指缩放 · 轻触查看”。
- 信息卡片从底部显示，建议最大高度约为屏幕的 40%；较长内容在卡片内部滚动。
- 关闭按钮保持足够的触控面积，卡片内操作不触发场景旋转或场所点击。

### 5.3 场所信息卡片

内容顺序：图标与场所名称 → 一句定位 → 简短介绍 → 阶段说明 → 关闭按钮。

示例：

> OPC 教学楼
>
> AI 学习与成长入口
>
> 未来汇集课程导航、知识库、学习路径和班级空间。
>
> 第一阶段仅展示场所定位，课程与班级入口将在后续开放。

第一版不展示可操作的“进入场所”按钮。数据与组件为后续 route、externalUrl 或进入动作保留接口。

### 5.4 镜头与选择反馈

- 默认正交相机、约 45 度斜俯视，首屏展示完整或大部分小镇。
- 支持有限角度旋转与缩放；不开放自由平移，避免轻易丢失场景。
- 限制镜头俯仰与缩放，避免看到地下或进入建筑内部。
- 选中反馈优先使用建筑底部光圈或场所边界高亮，避免依赖较重的后期效果。
- 同时只选中一个场所；点击另一场所直接切换。
- 点击空白区域或卡片关闭按钮取消选中；拖动结束不应误触建筑。

## 6. 居民与环境

- 一个蓝白配色的简化小人位于中心广场，显示“小镇居民”标签。
- 可加入轻微待机起伏，但不随点击移动，也不实现角色控制。
- 水景以低复杂度色块与岸线表达；首版不依赖复杂水面模拟。
- 棕榈树、路灯、座椅少量重复使用，优先保证建筑与道路可辨识。
- 公告屏和任务公告牌作为外观占位，不加载动态公告或真实任务。

## 7. 后续开发批次建议

每批开始前单独提出实施清单，用户确认后才开发。顺序可根据用户反馈调整。

| 批次 | 拟开发内容 | 用户可查看的成果 |
| --- | --- | --- |
| A | 基础项目、全屏场景、底座、简化道路、相机和灯光 | 可打开的空小镇底盘，验证视角和整体比例 |
| B | 六个场所外观、中文标签、场所配置数据 | 能辨认功能分区的小镇静态全景 |
| C | 场所选择、高亮、信息卡片、镜头及触控完善 | 六个场所均可操作的原型 |
| D | 居民、水景、绿化和少量公共设施 | 完整首版氛围 |
| E | 构建检查、桌面与移动布局检查、性能调整和异常提示 | 可交付首版及运行说明 |

各批次完成后先运行和检查，报告已完成内容与限制，再提出下一批清单。每批包含与该批相关的基本检查，最后一批进行整体检查。
