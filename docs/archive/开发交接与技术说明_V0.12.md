# 五六零人工智能AI小镇｜开发交接与技术说明

版本：V0.12，包含任务墙缩小、固定门口导航及门头细线移除的后续修订。  
资料日期：2026-09-18。  
用途：供接手开发者或 AI 理解当前成果、实现位置和开发约定。配套《宣传文案AI交接资料_V0.12.md》可以单独转交文案 AI。

## 1. 项目定位与当前阶段

正式名称：**五六零人工智能AI小镇**。公司全称：**五六零人工智能科技（北海）有限公司**。

项目是浏览器中的 3D 小镇场景原型，围绕学习、创业、创作与社区生活构建七个主题街区。当前已具备全景浏览、角色漫游、NPC 场景对话、发言气泡、座椅休息和动态交通等基础体验。重点仍是场景视觉与交互验证，并非完整业务平台。

以北海、北部湾和海浪为灵感，不是北海真实地图、现实园区复刻或已经建成的线下园区。最新外观为明亮蓝白微缩沙盘，布局以用户最终参考图及后续修订为准。

工程：`F:/AIwork/codex/560_OPC_3D_Town`。本机预览：`http://localhost:3000/`；这是本地地址，不是公众体验链接。本次工作未发布到外网。

README 中的 V0.12 表示开发批次，`package.json` 包版本仍为 `0.1.0`，两者不要混淆。

## 3. 已实现的体验与操作

| 模块 | 当前行为 | 边界 |
| --- | --- | --- |
| 游客与全景 | 无需登录，旋转、缩放、俯视、恢复全景 | 没有账号与权限系统 |
| 步行 | 绿色本地角色，第三人称跟随与第一视角 | 可浏览建筑外部公共空间，没有室内 |
| 导航 | 六个固定目的地，每次回到相同门口与朝向 | 七个街区不等于七个快捷按钮 |
| NPC | 32 位演示居民随机走动、停留、转身和避让 | 不是真人，不是大模型智能体 |
| 对话 | 靠近按 E/点击提示，按区域随机显示预设台词，可继续聊一句 | 台词来自本地配置，无后台管理界面 |
| 发言 | Enter/“说句话”，最多 60 字符，完整 emoji 按一个计，气泡约 8 秒 | 仅本地显示，没有多人消息同步 |
| 长凳 | 12 张均可 E/点击坐下与起身，玩家显示坐姿 | 起身寻找安全落点，被占用时保留坐姿并提示 |
| 交通 | 12 种车型，稀疏循环、车距控制、路口调度和行人让行 | 同时最多 8 辆；不可驾驶 |
| 环境声 | 本地合成“海风轻浪”，默认关闭，可手动开关和调音量 | 不是某个版本的《New Morning》录音 |
| 天空、地标 | 本地蓝天白云贴图；蓝色 560 与海浪组合约 80 秒转一圈 | 页面隐藏或减少动态效果设置会抑制动画 |

电脑：WASD/方向键移动，Shift 加速，拖动转向，E 互动，Enter 发言。Esc 先关闭 NPC 对话，否则返回全景。手机：虚拟摇杆移动，拖动视角，点击交互提示。

坐姿下可以环顾、切换视角和发言，移动暂停；导航至其他街区会结束坐姿。输入中文期间避免触发移动或互动快捷键。座椅提示优先于附近 NPC，不能同时触发两个动作。

## 4. 最新视觉决定

- 主门名称始终为“五六零人工智能AI小镇”，蓝白校园式门头，字牌左右留白已加宽。
- 门头电路纹样和上方波浪细线均已移除，保留建筑框架与两侧蓝底白字对联。面对入口，右侧“智汇五六零启新境”，左侧“梦起北部湾创未来”。
- 广场的立体海浪雕塑不受门头细线移除影响。蓝色 560 与海浪整体缓慢旋转，不恢复旧白线或浅色数字方案。
- 主体白墙蓝窗，创业园暖沙、社区薄荷绿、服务中心珊瑚橙屋顶、商业街蓝橙遮阳棚，辅助色保持克制。
- 服务中心招牌仍为蓝白，仅屋顶改色；不恢复“政务大厅”名称。
- 街区立体字为白色，侧面浅色，无黑色字阴影。不同街区框架有不同造型，并随文字牌面调整尺寸。
- 任务墙曾放大，后缩至该版的 72%；当前底座宽约 18.3、顶部高度约 8.1 场景单位，保留三栏九卡，减少对 AI 广场遮挡。这不是现实米数。
- 地图底座完整，边缘道路不外凸。车辆从四角循环，边界附近淡出/淡入。
- 玩家头顶显示小绿色箭头，不显示姓名。首页七区长条介绍已去掉，底部显示公司全称。
- 不恢复发展预留区、扩展区标记或旧深色木桌沙盘风格。

## 6. 技术栈与运行

本机 Node.js 24，PowerShell。依赖声明：Next.js 16.3.5、React ~19.2.0、Three.js ^0.183.0、React Three Fiber 9.7.0、Drei 10.7.8、TypeScript ^5.9；精确安装版本以 `package-lock.json` 为准。

项目根目录中执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

生产预览：

```powershell
npm.cmd run build
npm.cmd run start
```

交付检查：

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

已有进程占用 3000 时先核对归属，不误停其他程序。生产预览修改代码后须重新构建和重启服务，仅刷新网页不够。

最近已完成交付有 21 项测试，覆盖布局、公共区域可达性、碰撞、交通、NPC、发言与座椅。桌面及 390×844 手机尺寸进行过浏览器验证；手机为尺寸模拟，不代表实机性能结论。

## 8. 接手开发约定

1. 每批功能先列简要清单，用户确认后再开发。既往批准不覆盖新的业务，本文件也不是新功能授权。
2. 最新用户要求和当前代码优先于旧草案。历史 `docs/项目方案草案_V0.1.md` 等保留了已替换的名称和构想，不应整份重新实施。
3. 修改 Next.js 代码前阅读 `node_modules/next/dist/docs/` 对应说明，注意版本差异。
4. 场所稳定 ID 与外观分离；移动立柱、建筑、任务墙或家具时，同步碰撞及导航，验证通路。
5. 全景与步行复用相机实例，保留响应式阴影配置切换及页面隐藏/减少动画设置的处理。
6. 大量采用本地程序化几何和实例化渲染，无远程 3D 模型依赖；天空、音频也为本地资源。
7. 新增字牌文本要补全本地字形，并检查覆盖，避免“创作工坊”一类缺字问题。
8. 保持 E 键互动优先级、中文输入保护、起身安全落点与导航输入清理逻辑。
9. 环境声每次加载默认关闭；只记忆音量，默认 12%，NPC 对话中降至设定音量的 26%，页面隐藏暂停。
10. 不随意恢复被用户移除的装饰线、电路纹、姓名标签、黑色字阴影、道路外凸或过大的任务墙。

## 9. 未完成的业务与后续方向
