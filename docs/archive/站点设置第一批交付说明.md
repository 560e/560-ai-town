# 站点设置第一批交付说明

日期：2026-09-19。对应《系统设置完整规划_V1》第一批；后续账户安全、短信、认证、组织和版块业务仍未纳入本次实现。

## 使用入口

超级管理员登录个人中心，进入系统管理后台，选择“系统设置”。原有运行环境信息移到“运行状态”。运营中心侧栏和概览的“七区运营”已统一为“版块管理”。

## 实际可用功能

- 站点与品牌：上传首页Logo、浏览器图标、分享封面；编辑品牌文字、页面标题和站点简介。页面标题及简介同时作为分享标题和简介。
- 公司与备案：公司全称、版权说明、ICP备案号及HTTPS查询链接、公安联网备案号及HTTPS查询链接。
- 两组独立编辑，预览后点击“保存本组并生效”；保存前不改变正式页面。
- 桌面/手机宽度预览、最后修改人/时间、配置版本、最近20条历史内容；历史数据保留在数据库中。
- “预览上一版”展示本组最近一个不同配置，确认后仅恢复该组；生成新版本并记录日志。
- 版本冲突返回明确提示，保留当前输入，用户主动重新读取后继续编辑。
- 未保存编辑在链接跳转和刷新离开时提示。未设置图片和备案字段时保持默认数字560和空备案状态。

公司和备案信息共用于欢迎页、小镇、个人中心、运营中心及系统后台。小镇控件根据页脚实际高度留出空间。首页品牌与小镇网页标识同步，3D模型门头、雕塑和建筑招牌不变。

## 上传与数据

- 支持PNG、JPEG、WebP；上限2MB，最长边4096像素，像素总量受限，不接受SVG和动画图。
- 后端检查实际格式并解码，去除原始元数据，重新生成最长边不超过1920像素的WebP。
- 资源存放于项目根目录 `.local/site-assets/`，数据库保存标识、尺寸、大小与上传者；URL由随机UUID生成。
- 图片用于公开站点素材，上传前界面明确提示勿上传私密文件。未保存的图片不自动出现在页面中，但素材URL可公开读取。
- 本期不提供删除历史资源按钮，替换Logo后旧图片仍保留，保证配置恢复可用；每位超管每小时最多上传30张。
- 部署/备份须同时保存PostgreSQL数据和 `.local/site-assets/`。不能只复制源码或只备份数据库。

新增表：`town_site_settings`（当前发布配置）、`town_site_versions`（快照历史）、`town_site_assets`（图片记录）。`npm run db:migrate` 可重复执行，不覆盖已有配置。

公开接口仅返回品牌、公司、备案等展示字段，不返回人员、私有入口、安全设置和密钥。所有写接口和历史接口要求实时核验超级管理员身份；写入前在事务中复核操作者资格。公开配置读取失败时降级到默认展示；后台读取失败会提示错误。

## 关键文件

- `lib/site-settings.ts`：公开配置结构、默认值、字段与链接校验。
- `lib/server/site-settings.ts`：读取、事务保存、版本冲突和恢复。
- `lib/server/site-assets.ts`：图片验证、重编码与本地持久化。
- `components/account/SiteSettingsEditor.tsx`：编辑、预览、保存和历史界面。
- `components/site/`：统一品牌、页脚和公开配置上下文。
- `app/api/system/settings/route.ts`：超管配置读写。
- `app/api/system/site-assets/route.ts`：超管上传。
- `app/api/site-settings/route.ts`、`app/api/site-assets/[id]/route.ts`：公开展示数据和图片。
- `app/layout.tsx`：服务端页面标题、描述、图标与分享信息。
- `app/site.css`：设置页面、响应式预览、页脚和行走控件留白。

## 验证

32项项目测试、84项账户与设置集成检查通过，TypeScript类型检查和生产构建通过。集成检查包含：游客/居民/运营权限、跨来源限制、格式与超限图片、备案链接、数据库持久化、页面元信息、公开字段范围、配置日志、过期和并发编辑冲突、按组恢复。

浏览器已验证桌面与390×844手机界面、设置预览、真实保存与恢复、前台页脚同步、行走导航和视角切换。浏览器验证使用临时版权文字，已通过后台恢复为空；备案号码保持为空，没有填写虚构备案。保存和恢复留下两条真实验收记录。

手机尺寸模拟不替代真实设备GPU性能验证。新上传图片需在后台保存该组后生效，其他已打开页面刷新后获取最新信息；搜索和社交平台的缓存更新不由本站控制。
