## 五六零AI社区：用户的小区

定位为小镇的居住与日常生活板块，与办公园区、商业街形成区别。

本批场景任务：

1. 参照右下角组团，设计两组、约四栋蓝白住宅楼；用阳台、窗台花箱、单元入口和楼栋号体现住宅特征。
2. 朝南布置“五六零AI社区”入口门牌，衔接南侧人行道；另设通往商业街方向的步行连接。
3. 住宅之间保留公共院落，加入小型水景、步道、草坪、绿篱、长椅和休闲廊架。
4. 设置散步与停留的居民路径，使活动发生在庭院和小区步道上。
5. 近景重点完善单元门、阳台、院落入口及街道家具；本批开放外部公共空间浏览。
6. 配置独立社区 ID、住宅楼栋 ID 与入口位置，方便以后另行确认用户与住宅的关联功能。

后续需单独确认的业务：用户分配住房、个人住宅主页、室内装修、好友拜访、住宅权限与数据存储。本批不实现这些业务，也不把演示居民绑定为真实用户。

## 近距离浏览

沿用上一轮提出的两种浏览模式：

- 全景：旋转、缩放、俯视与恢复全景，初始构图对照本次参考图。
- 步行：透视相机、接近人物眼高；电脑使用 WASD/方向键移动和鼠标转向，手机使用虚拟摇杆移动与拖动转向；提供返回全景。
- 对建筑、围栏、水景设置基本阻挡，限定场地边界，入口和公共通道可正常通行。
- 建筑所有可见面补齐细节，路面、店招、门窗在近景下可辨识。
- 调整并增加街区活动居民；图中车辆作为静态场景细节，不加入车辆驾驶或交通模拟。
