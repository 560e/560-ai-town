# 第八批：海浪雕塑与街区配色（V0.8）

用户确认方案后实施，保留七区布局与既有交互。

## 设计修改

- 560 后方原白色弧线替换为有厚度的卷曲海浪图标。蓝色浪体、青色水纹和白色浪尖组成清晰的层次；正反两面都有配色。
- 数字、海浪和上层圆形展示台共用旋转组，正常帧率下约 80 秒一圈。外侧水池保持稳定；跟随原有减少动态效果及页面隐藏开关暂停动画。
- 创业园四栋建筑使用同一暖沙色系的细微变化，应用到屋顶、屋檐、门雨棚和少量外墙装饰。
- 社区住宅使用薄荷绿色系，应用到屋顶、檐口、阳台与局部外墙；白色仍占建筑主体，窗户延续统一蓝色。
- 学院和政务大厅保留蓝白，商业街保留蓝橙搭配，任务广场保留绿色标识。没有增加换肤界面。
- 配色规则独立放在 `data/skins/building-colors.ts`，建筑占地、层数、道路与碰撞数据均沿用原配置。

## 验证

- 类型检查、15 项现有测试和生产构建通过，涵盖建筑尺寸、场地布局、碰撞、NPC 漫步与交通等。
- 浏览器检查桌面及 390 × 844 手机尺寸：海浪立体轮廓、整体旋转与楼栋配色正常显示；进入小镇、人物和操作界面仍正常。
- 浏览器没有报告运行错误。手机检查为浏览器尺寸模拟，不代表真实设备性能测试。
