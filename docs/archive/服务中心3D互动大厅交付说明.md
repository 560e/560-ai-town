# 服务中心3D互动大厅交付说明

日期：2026-09-19。范围：用户确认的单层轻量3D大厅、接待NPC、两组身份展示板、办理台、个人办理、休息座椅及出口。

## 使用方式

进入 `/service` 默认直接操控绿色小人，使用统一的全屏互动视角，不再区分“大厅全景”和“走进大厅”。初始镜头拉近，桌面尽量保留完整大厅，手机呈现较大的局部视野。鼠标或触摸拖动旋转，滚轮或双指连续缩放；点击3D展示板、NPC、柜台和查询屏，可打开业务面板。右侧“便捷办理”也可直接进入展示板、我的办理和向导介绍，不要求走到指定位置。

进入后即可WASD/方向键移动、拖动旋转、Shift加速，靠近设施后按E或点击提示互动。手机使用左下角摇杆。底部导航将角色放到各区域固定且可通行的落点，清除原来的移动输入，保留当前缩放距离和角度。Esc仅用于关闭业务面板，不切换场景模式。

两张休息长凳均可坐下，坐下后移动暂停，再按E/点击起身恢复。坐姿继续使用小镇现有绿色角色模型和箭头，不增加头顶姓名。

大厅出口和右上角“返回小镇”回到小镇服务中心门前；门口按一次E或点击入口标记直接进入大厅。直接刷新小镇首页仍遵循原来的欢迎页规则。

## 业务连接

- 权限称号展示板与荣誉称号展示板读取已有公开目录，3D牌面只显示简要名称、数量和入口。公开内容多时，在面板内查看完整列表和筛选。
- 接待NPC“小零”使用运营已发布的欢迎语与办理说明，引导用户查看称号或个人进度。
- 详情、登录、动态表单、保存草稿、提交审核、补充资料、撤回、申请历史、个人称号及资料阅读复用已有页面组件和接口。
- 从大厅打开上述功能时，使用同一个可滚动业务浮层，保持 `/service` 页面和角色位置。保存草稿后可在浮层内进入申请详情，个人进度和资料链接也在浮层内切换。
- 浮层打开时暂停移动，背景不可点击，键盘焦点限制在面板中；关闭恢复场景焦点。未保存的申请输入离开前会提醒，保存过程中避免关闭面板。Esc也遵循这一规则。
- 原有详情、个人申请及资料独立路径保留，便于直接访问和分享。权限仍由服务器校验，3D入口没有新增或绕过授权。
- 没有公开称号时显示真实空状态，不预置固定学员/OPC称号。本轮两条展示称号和一条临时申请已清理，未授予正式身份。

## 运行成本控制

大厅与小镇使用独立路由；切换后卸载原场景，并非在小镇上叠加第二个Canvas。大厅复用现有Three.js组件、本地角色、实例化建筑部件与材质，没有新增第三方依赖、远程模型或纹理。

建筑、地砖、家具和NPC使用实例化方块；中文招牌由本地Canvas生成纹理并在卸载时释放。只设置一位接待NPC，没有人流模拟。统一互动视角连续渲染，面板打开或页面隐藏后切换为按需渲染。

手机视口使用DPR 1并关闭动态阴影与抗锯齿，以较近的初始镜头避免把整个大厅缩成小模型；需要查看边侧设施时可以走动、缩小或使用导航。若WebGL不能显示或上下文丢失，保留业务面板入口，可重试场景。此处理不能替代低端真机的性能测试，本次没有承诺具体帧率。

## 开发位置

- `app/service/page.tsx`：大厅路由入口。
- `components/service/hall/ServiceHall.tsx`：界面、导航、互动、摇杆、场景和业务面板生命周期。
- `components/service/hall/HallScene.tsx`：单层大厅、招牌、NPC、家具等本地几何。
- `components/service/hall/HallCanvas.tsx`：相机、键鼠控制、渲染和WebGL异常处理。
- `components/service/hall/HallPanel.tsx`、`components/service/ServicePanelContext.tsx`：业务浮层、内部导航、未保存提示和焦点管理。
- `data/service-hall.ts`：设施位置、碰撞、落点、移动与座椅规则，独立于外观。
- `app/service-hall.css`：桌面、手机、业务浮层和底部公司信息适配。
- `components/town/TownPlayer.tsx`：沿用原模型与坐姿，新增可选地面高度，原小镇默认高度不变。
- `tests/service-hall.test.ts`：大厅设施可达性、移动碰撞、座椅与导航状态。

不需要新增数据库迁移、环境变量或服务端口。
