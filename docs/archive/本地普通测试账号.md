## 使用

打开本地站点的登录／注册页面，输入手机号，先点击“获取验证码”，再填写5600登录。验证码5分钟有效，每次成功登录消耗一次，再次登录需要重新获取；保留60秒重发间隔和原有失败次数/请求频率限制。页面获取到测试验证码后自动切换为4位输入。

当前浏览器若已登录管理员，请使用独立浏览器测试或自行退出切换；创建账号不会替换当前管理员会话。

## 启用范围与维护

仅当 `.env.local` 的 `TOWN_LOCAL_TEST_RESIDENT=1`、`TOWN_LOCAL_AUTH=1` 同时满足，且运行模式不是production、认证地址为本机时生效。其他手机号仍使用随机6位验证码。请求继续经过原有本机、来源和接口权限校验，不发送真实短信。

测试账号被停用或被授权为管理角色时，固定验证码流程拒绝认证。不要把该测试账号用作正式管理账户。

删除或关闭 `TOWN_LOCAL_TEST_RESIDENT` 后恢复正常随机验证码逻辑；原账号资料保留。正式生产模式不会启用固定验证码。

重建本地普通测试账号的幂等命令：

```powershell
node --experimental-strip-types scripts/local-test-resident.ts
```

仅对指定本地数据库执行；已存在的普通账号保留资料，拒绝覆盖已停用或已提升权限的账号。创建行为写入审计。
