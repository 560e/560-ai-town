# 第二批：滨海微缩沙盘 V0.2

日期：2026-09-18。

## 本批授权

用户确认底模与默认皮肤分离、六处建筑细化、材质光影、六位固定路线居民及桌面/手机检查，并要求整体风格与配色参考其微缩工地沙盘截图。

## 视觉结果

- 保留北海滨海概念布局，以深青灰环境、木质底板、层叠海岸表现桌面模型。
- 暖米色墙体、灰绿色道路、深青色窗框和屋顶，搭配芥末黄与橙色细节。
- 政务大厅门廊、双层教学楼、多层写字楼、三间遮棚商铺、带公告栏的任务广场和中心景观，均由本地几何体生成。
- 加入路灯、长椅、矮墙和六位方块风格居民。居民沿固定道路往返，端点停留，行走时四肢摆动。并非用户操控角色，也没有多人同步。
- 后台标签页及系统“减少动态效果”状态暂停居民动画；手机降低阴影贴图尺寸，像素比上限 1.5。

## 底模与皮肤

`data/places.ts` 保留场所身份、位置、占地、高度限制。`data/town-config.ts` 保留场地、道路和镜头。为连通行走路线，东侧连接路延长 2 个场景单位，补齐接缝；无新增发展道路。

`data/skins/coastal-diorama.ts` 集中默认外观的颜色、灯光、建筑造型类型、高度、居民服装和界面色。`diorama-models.ts` 生成建筑构件，并在占地和高度限制内使用。原建筑占位组件替换为 `TownBuildings`，重复构件通过实例化绘制。

当前只有一套外观；没有主题切换按钮或第二套主题。后续更换模型仍需要制作资源、遵守布局边界并验证，不能把任意图片直接变成可交互小镇。

## 验证

- TypeScript 检查与生产构建通过。
- 6 项测试通过：场所占地不重叠、海岸边界、道路接入、建筑皮肤尺寸、居民完整周期路面范围及建筑避让、移动/停留/返程连续性。
- 桌面 1440×900，手机 390×844、320×740 与横屏 844×390 检查；验证缩放、俯视与恢复全景，页面无横向滚动。
- 浏览器未发现运行错误；依赖存在 Three.Clock 弃用提示，不影响当前渲染。
- 手机检查使用浏览器尺寸模拟，未做真实手机 GPU 帧率及触控性能测量。
