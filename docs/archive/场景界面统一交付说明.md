# 场景界面统一交付说明

日期：2026-09-19。已确认范围：小镇全景、小镇步行、服务大厅及六个介绍子页面的统一界面；不改变各中心的业务管理布局。

## 已完成的界面规则

所有三维场景采用相同的顶部品牌与场景卡片、右上角通用入口、底部主操作栏和临近互动区。公司信息在最底部独立显示，操作栏位置随实际页脚高度调整。

| 场景 | 底部主操作 | 状态与特殊能力 |
| --- | --- | --- |
| 全景沙盘 | 进入小镇、街区导航、镜头工具 | 登录居民可从左上角房间状态打开房间选择器；街区导航直达已有子页面 |
| 小镇步行 | 前往街区、说句话、第一/跟随视角、返回全景 | 前往街区到固定门口，临近时显示 E 互动；保留房间、公开气泡及双方私聊 |
| 服务大厅 | 大厅导航、身份与服务、我的申请、返回小镇 | 不显示房间号或多人聊天；保留展示板、申请、向导与长凳互动 |
| 六个介绍子页面 | 保留介绍内容与后续方向 | 复用品牌/场景标题和返回入口，继续标明功能筹备中 |

更多设置统一收纳环境声音、音量、操作说明及当前场景介绍。环境声仍默认关闭、手动开启；关闭设置面板不卸载播放器。小镇介绍返回欢迎页；大厅介绍打开小零的接待说明。

街区和大厅目的地默认收起。桌面面板居中，手机以底部面板展示；大业务表单和私聊保留自己的内容结构，同时统一圆角、关闭入口和移动端边距。电脑隐藏常驻摇杆，手机尺寸或触屏设备保留摇杆，E 互动按钮在手机右侧出现。

## 交互约束

- 每个场景底部最多四个主操作，不再新增独立漂浮菜单。
- 场景位置与多人房间号分别表达。没有实现多人能力的场景不能展示虚假的在线人数、切房或居民私聊入口。
- 场景导航选择后收起面板并恢复场景焦点；大厅导航后可直接按 E 办理。一般关闭设置则回到原触发按钮。
- 打开导航、设置、房间管理或私聊后，场景及背后的操作区不可操作，清理摇杆和移动输入。面板内支持 Tab 焦点循环和 Escape 关闭；切换到另一个弹窗时不抢夺新弹窗焦点。
- 服务大厅返回小镇直接到服务中心门口；六个介绍子页面返回对应门口。小镇进入个人中心前仍保存位置、模式和镜头，返回时恢复。
- 保留原有服务申请的未保存提醒，不用通用导航面板替代业务表单的离开检查。

## 组件与后续接入

`components/scene/SceneChrome.tsx` 提供：

- `SceneHeader`：传入场景名称、简短状态、右侧入口；`flow` 用于普通文档式子页面。
- `SceneDock`：组合当前场景的三到四个主要按钮或返回链接。
- `ScenePanel`：统一面板容器、标题、关闭行为、焦点恢复和键盘操作；内容保持挂载，避免设置关闭后声音重启。
- `SceneIcon`：本地图标，不依赖远程图形服务。

`SceneOptions.tsx` 复用环境声与操作说明。`app/scene-ui.css` 定义统一样式，并通过 `.scene-layout` 限制作用范围。新增三维场景时，在根节点使用该类，接入 Header/Dock/Panel，按实际业务提供导航和返回动作，同时将面板打开状态接入人物输入与镜头暂停。页脚高度用 ResizeObserver 写入 `--site-footer-height`。

本轮把 `TownExperience.tsx`、`ServiceHall.tsx` 接入上述组件，公开发言触发按钮嵌入底部操作栏。所有六个介绍页面继续由 `app/districts/[id]/page.tsx` 共享模板渲染。
