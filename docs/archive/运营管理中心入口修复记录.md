# 运营管理中心入口修复记录

日期：2026-09-19。

## 原因

此前随机管理路径仍渲染旧的 `AdminPage` 居民管理单页。3105端口的三中心HTML仅为设计原型，没有接入3000端口的实际页面。个人中心链接地址正确，但目标组件没有升级。

## 本次完成

- 随机运营入口改为 `ManagementCenter`，默认显示“运营概览”，采用新设计的侧栏和工作台布局。
- 分组导航包括工作台、用户管理、七区运营、内容运营和工作记录。
- 现有居民管理嵌入“居民管理”子模块，保留查询、详情、账户停用/恢复和用户操作记录。
- 新增真实账户统计：居民总数、正常账户、停用账户、近7天新增。
- “我的工作记录”读取当前管理员最近30条操作，不返回其他操作者的工作记录。
- 子模块使用同一私有路径的 `section` 查询参数，支持直接访问、刷新和浏览器历史；默认入口返回概览。
- 手机端使用可收起的侧栏，宽表格在自身容器内滚动。

无需更改已配置的随机地址，也无需访问3105原型端口。旧 `/admin`、`/manage` 仍为404。

## 仍待接入

七区和内容运营模块目前提供导航和明确的筹备说明，尚未开放编辑、发布、认证审批、课程和任务等业务。细分工作人员岗位权限及独立超级管理员中心也尚未完成。当前仍使用原有服务端管理员授权；本次修复不代表完整三中心批次全部交付。

## 主要文件

- `app/[managementEntry]/page.tsx`：私有入口目标组件。
- `components/account/ManagementCenter.tsx`：工作台、导航、工作记录与模块页面。
- `components/account/AdminPage.tsx`：现有居民管理的嵌入模式。
- `data/management-navigation.ts`：菜单、稳定模块ID与状态。
- `app/api/manage/overview/route.ts`：管理概览与本人工作记录，服务端鉴权。
- `app/management.css`：桌面和手机样式。

## 验证

类型检查、30项单元/场景/启动测试、38项账户集成检查和生产构建通过。新增检查覆盖新入口渲染、真实数据库统计、本人工作记录隔离、游客401和居民403。

浏览器实测从个人中心点击“进入运营管理中心”打开新版工作台；居民列表和详情正常；刷新后保持当前子模块；390×844手机布局、菜单展开和表格滚动正常。
