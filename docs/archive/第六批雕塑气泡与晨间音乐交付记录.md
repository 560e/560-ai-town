# V0.6 雕塑、玩家气泡与晨间音乐交付记录

日期：2026-09-18。用户确认“可以，按照这些先改吧”，并补充音乐“没有具体的版本，你可以寻找或者生成类似的”。

## 变更

- 所有主招牌、店铺招牌和楼号牌使用与窗户一致的蓝色 #1288d2；任务广场恢复 V0.4 的绿色 #18833f 和公告板 #208451，保留白色字体。
- 560 雕塑改成放大的蓝色实心字面、浅银包边和厚侧面，两层蓝白圆形基座。数字固定朝向主入口，背后的开放式银白弧环以约 60 秒周期独立缓慢摆转，遵循减少动态效果设置。
- 玩家头顶移除“我”文字，改为小型绿色向下箭头。
- Enter 或“说句话”打开输入，Enter/发送按钮发布，Esc/取消按钮关闭。按完整字符计数，最多 60 字；中文输入法组合过程不会因为确认候选的 Enter 误发送。空白输入不会发送。
- 发言在玩家头顶显示约 8 秒，轻微上浮淡出，跟随玩家位置；再次发送替换前一句。第一视角提供“你说”提示。输入期间暂停角色移动和 NPC 快捷键，关闭后恢复。内容按纯文本渲染，仅当前浏览器可见。
- 音乐更新为原创《晨光小镇 / Morning Light》：80 秒缓慢旋律、柔和程序化钢琴音色和延音和弦。它不是某首已发行的 New Morning 录音。保留音量设置、淡入淡出、NPC 对话降音量和后台暂停。
