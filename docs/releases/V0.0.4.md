## 保留数据升级

不要删除当前安装根、`.deployment`、数据库或上传素材。将本包解压到独立的新源码目录后，从其中执行：

```bash
sudo bash /新源码目录/560-ai-town-v0.0.4/deploy-linux.sh \
  --install-root /srv/560-ai-town
```

安装器在候选测试和构建均通过后才暂停旧服务，备份数据库、素材和配置后切换`.deployment/current`。失败时旧服务和数据不应被覆盖，数据库不自动回退。详见[部署运维手册第6节](../部署运维手册.md#6-升级回滚与诊断)。
