详见[部署运维手册第6节](../部署运维手册.md#6-升级回滚与诊断)。旧项目根、数据库、端口、管理入口与上传文件保持不变；新源码在独立候选目录解压，使用`deploy-linux.sh --install-root /既有项目根`。先检查及手工备份，候选构建通过后脚本短暂停服再备份、幂等迁移、切换与健康检查。保留旧版本，不删除.deployment。失败尝试恢复旧代码；数据库不自动回退。旧客户端注册缺name会返回400，应刷新使用新表单；既有账号无需更名，权限不变。
