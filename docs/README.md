## 当前采用版本

本地最新发布为V0.0.5完整源码包，支持新安装和V0.0.1保留数据升级。服务器最后确认仍为V0.0.1；新包不表示已部署。升级教程见运维手册第6节，实际打包校验见版本记录和发布收据。

## 阅读方式

接手开发先看功能状态，再按任务读产品和技术章节；维护服务器加读运维手册和对应版本记录；创作文案读宣传资料并核实实际开放范围。普通功能更新既有手册，不再新建“第几批交付说明”；每批必更新功能状态和CHANGELOG。

- [V0.0.4发布记录](releases/V0.0.4.md)：隔离候选回归测试环境，保留现有用户、数据库、素材和部署配置升级。

- [V0.0.2发布记录](releases/V0.0.2.md)：场景窗口、注册昵称、资料保存修复和保留数据升级教程。

- [V0.0.1发布记录](releases/V0.0.1.md)：当前2026-09-23完整部署与邀请码修订包、用户服务器验收及历史包记录，按批次和SHA区分。
- [版本记录模板](releases/版本记录模板.md)：未来正式发布时复制填写。

- 正式包保存当时的手册与文件校验清单。未来版本未发布前不建立冒充正式交付的记录。
